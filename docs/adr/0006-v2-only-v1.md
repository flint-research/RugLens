# 0006 — V1 simulates Uniswap V2-style WETH pairs only

- **Status:** Accepted
- **Date:** 2026-11-24
- **Context:** A correct V2 simulation (buy, approve, sell, fee-on-transfer support, reserve
  quotes) is feasible in the resource envelope. V3/V4, Algebra, and non-WETH quote assets require
  different router/pool semantics. Pretending to support them would create silent false
  confidence.
- **Decision:** V1 discovers pairs through each chain's configured V2 factory with the wrapped
  native token, and simulates with the corresponding V2 router. If no such pair exists,
  dynamic/liquidity coverage is lost and the report says so. V2/V3 expansion requires new venue
  adapters, tests, and coverage semantics.
- **Consequences:**
  - V3-only tokens tend toward UNKNOWN rather than a misleading verdict.
  - Blue-chip tokens without a V2 WETH pair need dataset notes or an adapter before FPR
    measurement.
  - Adding a venue is an explicit, testable change rather than a hidden heuristic.
  - Base uses BaseSwap V2; Ethereum uses Uniswap V2; BSC uses PancakeSwap V2.
